# LuminaWatch V5：先验设计稿，再动 App

> 2026-10-22。**设计与验收规格，尚未实施。**本轮不改 `app/` 源码、不重置用户数据、不重新打包 APK。用户提供的 `1.mp4` / `2.mp4` 是结构与运动参考；页面维持用户选择的白色，底栏提供深/浅切换，默认以深色参考为准。借鉴布局与交互，不复制 Apple 图标、商标或表盘作品。

## 二、统一版式（白色页面 + 可切换深浅底栏）

- 页面以近白底、深色正文、低对比中性分组为主。玻璃只用于底栏、必要的悬浮控件；不把所有内容卡都做毛玻璃。
- 一级页统一：安全区 → 大标题（约 32–34sp）→ 首要内容；滚动时标题可收起。水平边距以 16–20dp 起稿，所有章节左缘一致。二级页统一返回路径和紧凑标题。
- 设置组用一个连续容器和行间分隔线，不把每一行做独立大卡。图标尺寸、色彩、行高一致；有副标题的行不得截掉关键信息。
- 颜色职责固定：系统动作/链接一类强调色，小云品牌色只用于角色与内容插画，心情记录保留自己的情绪色。状态不得只靠颜色表达。
- 所有触摸目标不少于 48dp；动态字体放大时标题、标签和副标题可读。底栏不遮挡列表末项或系统手势区。

## 三、三大首页的定稿方向

### 1. 我的手表

视觉顺序：`所有手表` 入口 → 设备名/“我的手表”大标题 → 搜索设置 → `我的表盘` 标题与编辑 → 3 款表盘横滑预览 → 第一组真实设备设置 → 健康与陪伴。对照 `reference/v1/f_001.jpg`。

- 表盘预览取消目前的**大底色卡 + 大量文案**，缩略图在白底上横滑，露出下一张边缘。点击表盘先打开真实主题预览/图库，不在首页一次点击就隐式改变主题。
- 闹钟、连接与同步、小云形象、个人与隐私进入设备设置组；健康概览、心情、小云聊天、关怀进入“健康与陪伴”组。搜索继续过滤这些真实入口。
- 未绑定时明确“未连接”；不能伪装已连接、已下发表盘。首屏允许看到第一组设置的开头，不让表盘区占去半屏。

### 2. 表盘图库

视觉顺序：大标题 → 一张精选主卡（当前主题）→ 另外两款并排卡 → 本地预览状态说明。对照 `reference/v2/f_003.jpg`、`f_006.jpg`，只取图像占比、行列关系和滚动节奏。

- 三款真实本地主题分别可辨，不能仅靠同一个数字表盘换底色。此点属于**表盘视觉资产工作**，不能用占位截图冒充已经完成。
- 主题选择即时更新首页预览并持久化；“应用”文案必须说明只作用于 App，未向真实手表下发。
- 不出现不存在的在线分类、下载按钮或空的第四格；以后有真实主题再扩展网格。

### 3. 发现

视觉顺序：大标题 → “现在开始”图文行 → “了解更多小云功能”图文行 → 今日总览。对照 `reference/v1/f_081.jpg`。

- 每行约 70dp 的图像区只是内容缩略图，不做巨大的带阴影卡；文字部分有标题和一句说明，行间细分隔线。
- 认识小云、记录心情、心情月历、健康概览、关怀、小云对话/记忆、今日总览均落到真实页面。没有内容的项目不显示。

## 四、底栏单独验收：不能再只看截图

| 状态 | 深色默认 | 浅色可选 | 行为要求 |
|---|---|---|---|
| 静止 | 半透明深灰轨道；内部透镜略亮，图标与字清楚 | 半透明浅灰轨道；透镜仅微亮而非白色实卡 | 视觉宽度目标 220–250dp，高 54–58dp；三项完整可读 |
| 按下 | 触点周围高光增强，透镜轻微鼓起 | 高光不过曝，仍能看到背景 | 反馈在 100ms 内出现，取消按压可回到原状态 |
| 拖动 | 透镜连续跟手、轻微横向拉长，跨栏时图标/文字归属同步 | 同样手势、同样几何，不只换轨道颜色 | 拖动只在底栏区域响应；慢拖、快速反向都不中断或跳位 |
| 松手/点击 | 弹簧吸附目标槽位并切页 | 同左 | 透镜、选中语义、页面三者最终同一索引；点击也走滑行动画 |

设计稿必须同时画：深色静止、深色拖动中、浅色静止、浅色拖动中。Android 12 以下无实时效果时仍保留**相同几何和状态反馈**，用半透明实体降级，不能变成另一种布局。开启“减少动态效果”时关闭拉伸/色散，保留可理解的短位移或直接切换。

实现前置检查：`AppShell.kt` 的页面采样层只包含页面；底栏轨道与透镜的嵌套必须正确使用 Backdrop 2.0.0 背景导出/组合，避免自采样。不能靠把白色画到 70% 以上不透明度来“补玻璃”。

## 五、现有功能一个不删：入口与数据验收

| 功能 | 入口 | 必须保持的行为 |
|---|---|---|
| 设备绑定/状态、闹钟、形象、隐私 | 我的手表设置组 | 本地状态如实显示；闹钟增删改/开关；角色选择持久化；设置不丢 |
| 三款本地表盘 | 我的表盘 + 表盘图库 | 预览、切换、重启保持；未下发状态如实说明 |
| 健康概览/指标详情/问卷 | 我的手表健康组 + 发现 | 数据来源说明、指标详情、问卷流程/结果保留 |
| 心情三步记录/日历/详情 | 我的手表健康组 + 发现 | 原彩色云和滑块保留；选定日期保存、返回月历即时显示、同日多条及日期格云徽标保留 |
| 小云聊天/历史/记忆/形象 | 我的手表健康组 + 发现 | 历史消息、角色设定和本地记忆开关保留 |
| 关怀规则/时间线/详情 | 我的手表健康组 + 发现 | 规则、记录、详情和回访路径保留 |
| 今日总览 | 发现 | 闹钟、健康、心情和关怀摘要继续可达 |

二级页沿同一导航和排版系统重做，但**心情记录是例外保持页**：保留现有云 Path、分层、高光、呼吸、情绪色背景、滑块和三步填写；只统一导航、进度、边距、字阶和按钮尺寸。不能为追求白色风格而换成圆形玻璃球。

## 六、实施顺序与停止条件

1. **设计签收（本文件）**：先给三大首页与底栏的同尺寸对照稿；用户确认结构、配色与透镜形状。没确认不继续改代码。
2. **底栏独立样机**：只接假背景和三个标签，做可交互的深/浅原型；交参考帧、原型静帧和 60fps 拖动录屏。未达到“短、薄、连续滑动”就不接入主 App。
3. **壳层 + 三大首页**：逐页替换旧排版，保留既有导航和 `AppStore` 数据。每页交首屏/滚动到底截图；旧版与新版并排，一眼能看出结构变化。
4. **二级页**：先设备/闹钟/隐私，再健康/心情月历/问卷，再聊天/关怀/形象。每类做功能回归；心情记录按保持页处理。
5. **APK 验收**：同设备同尺寸对照 Apple 参考（深色结构、白色变体）、旧 APK、新 APK；底栏慢拖/快甩/反向/点击、深浅切换、重启、滚动避让、字体放大、TalkBack、API 26/31/33+。不以 `BUILD SUCCESSFUL` 代替视觉和交互验收。

**停止条件：**若设计稿中底栏仍接近全宽、选中态仍是实心卡、首屏设置组仍被巨大的表盘区挤出、或任一现有功能入口消失，退回设计阶段，不打“新版 APK”。
