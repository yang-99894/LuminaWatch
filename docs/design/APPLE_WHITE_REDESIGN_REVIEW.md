## 6. 与当前实现的差距清单

**P0（影响“像不像”与可用性）**

1. 底栏选中态为橙色大胶囊，目标为浅灰选中，橙色只用于手表/表盘操作。
2. 页面大量白卡 + 阴影 + 彩色图标块；目标为 `#F2F2F7` 分组 + 0.5px 分隔线，无卡片阴影。
3. 我的手表右上齿轮、设备行层级与参考不一致；目标把设备作为行，大标题为「我的手表」。
4. 表盘图库缺少 Hero 与两列分类网格。
5. 发现页是功能分组列表，缺少内容型大图标入口。
6. 健康/心情/聊天/闹钟仍是旧卡片与渐变，需要按模板重绘。
7. 内容卡片仍使用 Backdrop 玻璃（`FrostedCard`）；目标内容不用玻璃。

**P1（打磨）**

8. 设置行高、图标尺寸、分隔线起点未统一。
9. 心情三步的步骤条、CTA 情绪色、云图呼吸与低动态支持需统一。
10. 月历格边界与“有记录”标记不够明显。
11. 空态、来源标注、未连接/未同步提示需在新 UI 中更清楚。
12. 字号放大、TalkBack、48dp 触控、API 26/31/33+ 未系统验收。
