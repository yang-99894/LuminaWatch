## 2. 修订后的关键设计

### 2.1 “我的手表”顶部层级与真实行为

```text
所有手表 ›                 ← 14sp 橙色入口，进入设备列表
小云手表                   ← 34sp 大标题：已绑定显示设备名，未绑定显示“我的手表”
[🔍 搜索设置]              ← 本页设置行过滤，不联网
我的表盘            编辑
[纯白] [珊瑚] [深色] …
手表设置
闹钟 / 连接与同步 / 小云形象 / 个人与隐私
```

- **所有手表**：进入设备列表页。当前产品只有一台本地手表，列表显示“小云手表（已保存/未连接）”与“添加手表”；点设备进设备设置，点添加进绑定。**不伪造多设备、不伪造同步。**
- **搜索设置**：只过滤本页可见的设置行（闹钟、连接与同步、小云形象、个人与隐私、健康入口等）；无结果显示“没有找到相关设置”；不请求网络、不搜索聊天或健康数据。
- **大标题**：已绑定用设备名（对应录屏的设备名大标题）；未绑定用“我的手表”。此点列入待确认问题。
- 参考帧：`reference/v1/f_002.jpg`（1.mp4 00:01）。

### 2.2 表盘图库：只展示真实存在的 3 款

- Hero 为**当前选中主题**的大预览，副标题“当前：纯白 · 仅手机预览，未下发手表”。
- 下方 `全部表盘（3）` 列表：纯白 / 珊瑚 / 深色，每行可点选，选中打勾；没有“查看所有表盘”、没有“下载”、没有新分类。
- 时间文字在白色表盘上使用 `#1C1C1E`，修复白底白字。
- 未来若要新增第 4 款，需新增 `face_theme` 值并做旧数据兼容，不在本轮偷偷加。

### 2.3 心情：层叠玻璃云 + 三步对齐 + 动态

- **云的结构**：5 个半透明圆盘叠成云形，每层有 1.5px 白色高光边、顶部镜面高光、底部内阴影和暖色透光；层与层交叠处自然加深，不是单色块。
- **随滑动变化**：情绪值 0–1 连续驱动云的缩放、上浮/下沉、色相（冷灰 → 暖橙）和透光强度；过渡 150–300ms，可中断；系统“减少动态效果”时停止呼吸，只保留即时颜色变化。
- **三步同基线**：顶部返回/标题、4dp 步骤条、底部 52dp CTA 在 1/3、2/3、3/3 完全同位置；第 1 步保留“当下感受 / 今天整体感受”范围选择。
- 第 2 步：1–3 个情绪词 chips + 已选预览；选满 3 个后其余置灰并说明。
- 第 3 步：影响因素 chips + 可选备注 + “保存这次心情”。
- 动态示意：[mood_cloud_states.png](mockups/mood_cloud_states.png)（5 个关键帧）与 [mood_cloud_morph.gif](mockups/mood_cloud_morph.gif)（循环播放）。

![云随情绪值变化](mockups/mood_cloud_states.png)

### 2.4 心情月历：小云缩略图 + 数量

- 每个有记录的日期格底部显示**小云缩略图**（不是色点）；同日多条在右上角显示数量徽标（如 `2`）。
- 选中日期用暖橙描边 + 浅底；下方列表标题显示“10 月 20 日 · 2 条”，逐条显示时间、词与因素。
- 当前实现已有云缩略图与 `+N`，本稿保留并统一尺寸/位置，不新增数据字段。

### 2.5 发现：内容型排版

- 去掉 `F2F2F7` 分组卡片；改为录屏式大图标（56dp）+ 标题/副标题 + 右箭头，行间 0.5px 分隔线。
- 两段：`现在开始`（认识小云 / 记录一次心情 / 查看健康概览）、`了解更多小云功能`（关怀与提醒 / 小云对话与记忆）。
- 入口仍保证核心功能 ≤2 次点击；不放工具九宫格、不放无内容卡片。

## 5. 与当前实现的主要差异（按修订稿）

1. 我的手表补“所有手表 + 搜索”；当前只有大标题和设备行，缺这两层。
2. 表盘图库改为“当前主题 Hero + 3 行真实选项”；当前是横滑三卡 + “按风格浏览”，且无 Hero。
3. 心情云从当前的分层轮廓（偏实色）改为半透明玻璃盘；CTA 与三步基线统一。
4. 月历从“云缩略图 + `+N`”统一为“云缩略图 + 数量徽标 + 当日列表”，当前已接近，需调尺寸与选中态。
5. 发现从分组列表改为大图标内容行；当前仍是 `健康与心情 / 小云 / 关怀` 分组。
6. 全局去除内容卡玻璃/大阴影；当前健康、设置等仍有毛玻璃卡与重阴影。
7. 底栏从橙色选中胶囊改为浅灰选中；当前为暖橙胶囊。
8. Android 不绘制 iPhone 画框；当前本来就没有，静态稿仅展示用。
