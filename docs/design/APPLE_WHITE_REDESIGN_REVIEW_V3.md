## 2. 具体做法

| 项目 | 当前 App | 新版（本稿） |
|---|---|---|
| 云 | `MoodCloud` 自绘 Path，4 层半透明轮廓 + 白色描边 + 中心高光 | **同一路径、同样 4 层**；只改为在白色底上呈现，颜色仍由情绪值驱动 |
| 情绪色 | `moodColor`：蓝 → 青 → 绿 → 橙 | 不变；用于云、滑块、选中词、CTA |
| 页面底 | 整屏浅绿（情绪底色） | 白色，融入新白色界面；情绪色集中在云/滑块/按钮（**是否保留整屏浅色底待确认**） |
| 导航 | 圆形返回按钮 + “记录心情” + `1/3 · 选择感受` | 统一为 `‹ 记录心情` + 右侧 `1 / 3`；下方 3 段进度条 |
| 步骤 | 文字 `1/3`、`2/3`、`3/3` | 保留文字，增加同位置 3 段进度条；三步内容与顺序不变 |
| 滑块 | 圆角轨道 + 绿色填充 + 圆点 | 同一交互；轨道/圆点沿用情绪色 |
| 按钮 | 52dp 高、圆角、绿色 | 52dp 高、16dp 圆角、颜色取当前情绪色；位置固定底部 |
| 词语/因素 | 胶囊 chips，3 列换行 | 同样胶囊，选中用情绪色浅底 + 描边 |
| 保存 | `store.addMood(...)` → 回月历/来源日期 | 完全不变 |

### 2.1 三步结构（不变）

1. **1/3**：范围（当下/今日）→ 分层云 → 情绪名 → 滑块 → 下一步。
2. **2/3**：同一朵云缩小 + 情绪名 → 选 1–3 个词 → 下一步。
3. **3/3**：同一朵云 + 情绪名 → 影响因素 → 备注 → 保存这次心情。

三步的返回、标题、进度条、CTA 基线一致；云和情绪名在 2/3、3/3 继续显示，保持当前 App 的连续感。

### 2.2 云为什么还是“当前这朵”

- 直接复用 `MoodCloud.kt` 的 `cloudPath`：同一组 cubic 控制点、同一 `spread/lift/droop/float` 参数。
- 层数、描边宽度、白色高光、中心亮度都按当前实现，不改成圆盘叠加。
- 动效仍是 `animateFloatAsState(value, tween(220))` + 4.4s 呼吸；减少动态效果时停呼吸。
- 静态稿里的云是把该 Path 用 SVG 复刻后的示意，最终实现仍走 Compose 自绘，不引入图片资源。

## 3. 需要你确认的一点

**页面底是否保留当前整屏的情绪浅色底？**

- 方案 A（本稿）：白色页面，情绪色只出现在云/滑块/选中词/CTA，最贴合“新版白色界面”。
- 方案 B：保留当前整屏浅色底（如平静为浅绿），只把导航/按钮/字阶统一；更像现在的沉浸感，但与其它白页差异较大。

我默认按 A 出稿；如果你要 B，我只改背景层，不动云和流程。
