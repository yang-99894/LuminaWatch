## 1. 底栏：液态玻璃拖动

保留 Backdrop 1.0.2，未升级。

- **跟手**：选中块 offset 直接读取 `dragX`，拖动时不再等吸附；松手后 `onSelect` 切换 tab，`animateFloatAsState(spring)` 回弹。
- **玻璃**：底栏 `surfaceAlpha .70`，选中块 `#ECEFF4` / `.72` + 30dp blur + lens + 白色 1px 内边高光；不是不透明白/灰胶囊。
- **拖动形变**：拖动时按 `abs(dragImpulse)/slotWidth` 计算 `stretch`（上限 0.16），`scaleX = 1+stretch`、`scaleY = 1-stretch*0.22`；图标/文字选中时 1.04–1.07 放大。
- **点击**：位置 spring 过渡 + 图标/文字轻微放大；拖动/点击共用同一套 pill 位置动画。
- **可读性**：未选中 `#8E8E93`，选中 `#1C1C1E`，白色系。
- **底部安全区**：`LocalBottomBarInset` 96→120dp，`PageColumn` 底部留白 26+120。

实际拖动录屏：[bar_drag.mp4](baseline/bar_drag.mp4)
