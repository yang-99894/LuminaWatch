# V4 实施与验收记录（2026-10-21）

本记录对照 `APPLE_WATCH_WHITE_REDESIGN_V4_EXECUTION.md`。本轮保留业务数据结构与现有功能，不改变包名、签名、表盘下发状态或心情云的绘制逻辑。

## 已实施

- 底栏从近全宽 78dp 改为居中 216–252dp 自适应宽、56dp 高；图标/字阶缩小，选中透镜内收；按下微放大、横拖跟手、跨槽触觉反馈与松手弹簧吸附保留。内容页底部预留从 120dp 缩为 72dp，并额外避让系统导航手势区。
- 2026-10-21 补修：原拖动拉伸只取透镜与标签中心的距离，慢拖时放大几乎不可见；现改为整个拖动期间保持约 1.30× 横向、1.25× 纵向放大，浮起 7dp，图标/文字同步轻微放大，松手回弹。透镜色与边界也加深以适应白底。实拍：[`拖动中放大块`](baseline/v4_drag_held_final.png)。
- 我的手表首屏改为“所有手表小胶囊 → 设备标题 → 搜索 → 无大底卡的横向表盘预览 → 紧凑设置组”；健康与陪伴入口另组。所有原入口和本地预览功能保留。
- 表盘图库去除巨大暖色 Hero + 普通设置行，改为真实 3 款主题的两列视觉卡；点击即时更新预览，继续明确未下发真实手表。
- 发现页改为更紧凑的章节式图文内容行，去除页面中的设计说明文案。
- 二级页共用导航改为居中小标题、48dp 返回点击区；内容页去除装饰性大背景光斑，统一 12dp 基础竖向节奏。
- 通用黑色主按钮改为系统蓝色；健康页顶部黑圆按钮改为白底描边蓝图标；聊天发送按钮改蓝。隐私页“重置本机数据”改为次级按钮。心情记录自身的情绪色 CTA、背景、云和滑块没有改变。
- 闹钟列表从每条大卡改为紧凑设置组，并保留开关、编辑、删除、撤销、上限与本地未同步提示。

- 模拟器实拍：[`我的手表`](baseline/v4_watch_final.png)、[`表盘图库`](baseline/v4_gallery.png)、[`发现`](baseline/v4_discover.png)、[`闹钟`](baseline/v4_alarm.png)、[`心情记录`](baseline/v4_mood.png)。
