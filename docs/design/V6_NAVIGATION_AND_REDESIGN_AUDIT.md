# V6 导航与页面重设计核对表

日期：2026-10-22。此文档记录**当前真实状态**，不把编译通过等同于 Apple Watch 风格验收通过。

## 导航契约

| 入口 | 应打开 | 返回后应到达 |
|---|---|---|
| 我的手表 → 所有手表 → 当前设备 | 设备状态页；未绑定时由页内「绑定手表」继续 | 我的手表，保留滚动位置 |
| 我的手表 → 连接与同步 | 设备状态页；未绑定也不跳过状态说明 | 我的手表 |
| 我的手表 → 表盘卡片／编辑 | 表盘图库；打开本身不改变已选表盘 | 我的手表 |
| 设备状态 → 手表表盘 | 表盘图库一级页 | 表盘图库一级页 |
| 我的手表／设备状态 → 小云形象 | 仅 App 小云形象选择；表盘独立配置由明确入口进入图库 | 原入口页 |
| 发现 → 和小云聊聊 | 小云对话 | 发现 |
| 发现 → 小云记忆 | 小云记忆管理 | 发现 |
| 心情月历 → 日期 → 记录 → 保存 | 回月历所选日期，显示新记录 | 月历 |
| 关怀详情／心情详情 → 对话 | 对话，按来源设置或清空关怀上下文 | 原详情页 |

## 已确认并修复的错跳

1. 未绑定时「连接与同步」原本直接进绑定流程，现先进入设备状态页。
2. 设备状态页「手表表盘」原本进入「形象与表盘」，现切到表盘图库。
3. 「我的表盘」卡片原本点击即改选配色，现只打开图库，选择在图库内完成。
4. 发现页「小云对话与记忆」原本只进入记忆设置，现拆明入口语义：「和小云聊聊」进对话，「小云记忆」进记忆。
5. 「小云形象」原本混有第二套表盘选择，现分离，表盘编辑明确前往图库。
6. 从关怀／心情详情进入对话原本清空整个返回栈，现保留来源详情；同时修复无关怀来源时沿用上次关怀上下文的问题。

## 仍未完成的设计与验收

当前只是导航纠错及局部界面改动，**不是全 App 重新设计完成**。特别是健康与指标详情、今日总览、对话与记忆、关怀、闹钟、绑定、设置、欢迎页仍有旧版布局和组件；心情三步保留了原云朵，但页面框架也尚未逐帧对齐参考录屏。

后续按页面族交付，每族必须同时满足：入口与目标一致、系统返回与页面返回一致、浅／深色截图和 Apple Watch 参考关键帧并排比较、原功能与本地数据不丢失。未经截图及点击回归的页面标记为「未验收」，不能宣称一比一完成。真实手机打不开的问题需要该手机的崩溃日志独立定位，模拟器启动成功不能代替真机验收。
